# Pasta de Modelos de Embedding GGUF (`models/`)

Esta pasta armazena os modelos de vetorização quantizados no formato `.gguf` utilizados pelo provedor **Local Embutido (llama.cpp)**.

## Modelo Padrão Recomendado

- **Nome**: `all-MiniLM-L6-v2-Q4_K_M.gguf`
- **Tamanho**: ~23 MB
- **Link de Download Gratuito**: [HuggingFace - Second State All-MiniLM-L6-v2](https://huggingface.co/second-state/All-MiniLM-L6-v2-Embedding-GGUF/resolve/main/all-MiniLM-L6-v2-Q4_K_M.gguf)

Para utilizar o motor `llama_cpp`, baixe o arquivo `.gguf` acima e coloque-o nesta pasta `models/all-MiniLM-L6-v2-Q4_K_M.gguf`.
