# Pasta de Executáveis (`bin/`)

Esta pasta armazena o binário do executável **`llama-server.exe`** (Windows) ou `llama-server` (Linux/macOS) utilizado como serviço sidecar transparente de embeddings.

## Executável Recomendado

- **Nome**: `llama-server.exe` (Windows x64) ou `llama-server`
- **Projeto**: [llama.cpp Releases no GitHub](https://github.com/ggerganov/llama.cpp/releases)

Coloque o executável `llama-server.exe` nesta pasta `bin/llama-server.exe`.
