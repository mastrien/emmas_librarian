Introdução

Bem-vindo à wiki oficial do Emma's Librarian. Aqui você encontrará instruções detalhadas para aproveitar ao máximo todas as ferramentas disponíveis na suíte de pesquisa.

1. Busca Federada

A Busca Federada permite procurar artigos no Scopus e na Web of Science simultaneamente.

Configurando as Chaves de API

Antes de começar, você precisará adicionar as chaves de API nas configurações do sistema.

Usando o Construtor Visual

Adicione blocos lógicos como AND e OR para formar a sua string de busca. O sistema irá automaticamente traduzir isso para a sintaxe correta de cada base.

2. Biblioteca e Leitor de PDF

Toda sua bibliografia fica guardada no SQLite do projeto de forma local.

Lendo PDFs

Abra o leitor integrado, selecione qualquer texto e um menu pop-up perguntará se você quer destacar ou adicionar notas.

3. Inteligência Artificial (RAG)

Vá até a aba de Inteligência Artificial, selecione os PDFs que quer ler simultaneamente e crie suas perguntas. O modelo irá processar e gerar uma resposta fundamentada com base exclusivamente nos seus documentos.

4. Agenda de Pesquisa

Organize prazos e crie um cronograma visual para cada etapa da sua revisão sistemática.
